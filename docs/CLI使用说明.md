# 学生组织面试评分系统 —— CLI 使用说明（非技术版）

> 本手册面向学生组织面试官（无需编程经验）。先读「快速开始」，其余按需查阅。
> 开发者请另读 `接口文档.md`。

## 1. 快速开始（3 步）

1. **准备名单文件**：把各部门交来的 Excel/表格名单另存为“文本文件(TXT) 或 CSV”，放到本项目根目录，命名为 `名单.txt`。
   - 格式要求（系统会自动宽容乱序、多列、空格逗号等）：**每行一个人**，行内含：一段 ≥2 个汉字的姓名 + 恰好 10 位数字的学号。
   - 姓名含少数民族中间点的写法要带点（如 `麦麦提·吐尔逊`、`阿依古丽·买买提`），**不要**用空格分隔两段名字。
   - 表头行、电话、备注等其它文字不影响导入；纯乱码行会被跳过并在导入结果中列出（最多 3 行），方便排查。
2. **启动**：
   - Linux/macOS 终端：先 `bash scripts/fetch-libs.sh`（仅首次，联网下载一次组件），再 `bash scripts/build.sh`（首次编译），之后每次运行 `bash scripts/run.sh`。
   - Windows：双击 `scripts/fetch-libs.bat` → `scripts/build.bat`；然后打开 cmd 输入 `chcp 65001` 回车，再运行 `scripts\run.bat`。
3. **按菜单操作**：主菜单输入数字回车即可；输入 `0` 退出。数据自动保存在 `data/` 文件夹，下次启动接着用。

## 2. 主菜单速览

```
1 导入名单文件          6 分数补录（已结束面试的人补一条评分）
2 面试打分（逐人打分）   7 分数附加（才艺等加分，要写原因）
3 查看名单与状态         8 撤销最近一次评分操作
4 查看排名与评分明细     9 初始化系统（清空评分，保留名单）
5 导出 CSV（Excel 用）   0 退出
```

每次回到主菜单，顶部会显示：名单总人数、未面试/面试中/已结束人数、普通评分条数、附加分条数。

## 3. 典型完整流程（跟着做一遍）

### 3.1 导入名单（菜单 1）
- 直接回车 = 读取当前目录的 `名单.txt`；也可以输入其它路径（如 `samples/名单样例-规整.txt`）。
- 结束后显示：`成功解析 X 行（新增 N 人、更新 M 行）/ 跳过 Y 行`。
  - 新增=库里没有过的学号；更新=同一学号再次出现（按最新姓名更新，**不会重复**）。
  - 跳过行请对照源文件修正格式后重新导入（重复导入是安全的）。
- 想试玩：用仓库自带的 `samples/名单样例-规整.txt` 或 `samples/名单样例-乱序.txt`。

### 3.2 面试打分（菜单 2）
1. 输入姓名（几个字即可）或学号（可只输前几位）→ 回车搜索；
2. 看到匹配列表后输入序号**确认**人选（系统显示其状态）；
3. 进入面试界面：
   - `1 添加评分`：输入 0~100 的分数（可带两位小数，如 85.5），每输一条立即保存；
   - 想继续打分就再选 1；手误输错可选 `2 删除最近一条`；
   - 打完选 `3 结束评分`：
     - 有 3 条及以上：自动“去掉一个最高分、一个最低分”取平均，直接算出最终分；
     - 只有 1~2 条：系统会提示“无法去掉最高最低，将按普通平均”，问你是否确认——**确认则按普通平均结束，不确认则继续打分**；
   - 中途有事可 `0 暂存退出`，该人保持“面试中”，下次选菜单 2 会自动提示继续。
- 注意：**同一时间只能面试一个人**；想换人面试，必须先把当前这位结束（或先初始化）。

### 3.3 查看排名（菜单 4）
- 只给**已结束面试**的人排名：最终分从高到低；同分时学号小的在前。
- 表格里能看到每个名次的平均分（去极值/普通平均）、附加分合计、评分条数。
- 输入学号可看某人逐条评分明细（第 1 条、第 2 条…以及附加分项目和原因）。

### 3.4 导出 CSV（菜单 5）
- 范围：`1 仅已完成`（正式排名结果）或 `2 全部`（未完成者也带上，适合备份）。
- 路径直接回车即可（自动生成 `data/导出_年月日_时分秒.csv`）。
- 文件是 UTF-8 带 BOM：用 Excel 双击打开**不会乱码**；若个别电脑仍乱码，用 Excel“数据→从文本/CSV 导入”选 UTF-8。
- 列说明：排名、学号、姓名、状态、最终分、平均分、平均方式、附加分合计、评分条数、逐条评分、附加分（含原因）、完成时间。

### 3.5 面试打分后发现问题怎么办
- 该候选人**还没结束面试**：回到菜单 2，删除上一条评分（选 2）后重打。
- 该候选人**已结束**：
  - 漏了一条分 → 菜单 6 补录（输学号或姓名搜索后补），最终分自动重算；
  - 想加才艺分 → 菜单 7 附加（必须写原因，如“才艺加分”），直接计入最终分；
  - 刚输错一条 → 菜单 8 撤销：先看最近一次操作是什么，确认后删除并重算；可以连续撤销多次。
- **撤销范围**：只能撤“评分操作”（打分、补录、删分、附加），按倒序一次一步；不能撤过初始化；已结束者不能被撤到 0 条评分（系统会拒绝并解释）。

### 3.6 收尾与初始化（菜单 9）
- 全部面试完成、导出排名后，如想清空重来（如第二轮纳新）：选 9。
- 系统会先警告并**建议导出备份**（选 y 帮你备份 CSV），然后要求你输入 `YES` 二次确认。
- 执行后：所有评分、附加分、撤销记录清空，所有人回到“未面试”；**名单保留**，可继续导入新一批人。

## 4. 常见问题（FAQ）

| 问题 | 处理 |
|---|---|
| 导入显示“跳过 N 行” | 查看列出的样例行；通常是：该行没有 10 位学号 / 学号位数不对 / 一行挤了多人。修正后重新导入即可 |
| 名单里有人叫“阿依古丽 买买提”（空格） | 改成 `阿依古丽·买买提`（用中文输入法打出间隔号 `·`）后重新导入；重复导入会更新姓名，不会重复 |
| 导出 CSV 到 Excel 乱码 | 本系统已自动加 BOM 不会乱码；若用其它软件打开请选 UTF-8 编码 |
| 输错分数已保存 | 未结束面试：菜单 2 选删除上一条；已结束：菜单 8 撤销（一次撤一步） |
| 想给已结束的人补分 | 菜单 6（补录）；想加才艺分请用菜单 7（附加，需原因） |
| 中途退出程序 | 已录评分不会丢；重启后菜单 2 会提示继续当前候选人的面试 |
| 数据存在哪里 / 想备份 | 全部数据在 `data/scoring.mv.db`（一个文件）；备份=退出程序后复制该文件；恢复=放回原位 |
| 初始化后还能找回分数吗 | 不能。执行前请用菜单 5 或初始化流程内的“先备份”导出 CSV |

## 5. 数据安全小贴士

- 建议每轮面试结束导出一次 CSV（菜单 5 选“全部”），并复制 `data/scoring.mv.db` 到其它位置。
- 不要同时开两个程序窗口操作同一数据库。
- 名单文件建议保留原件，方便对照跳过行。
