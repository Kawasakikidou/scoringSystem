# 学生组织面试评分系统 —— CLI 使用说明（二期·非技术版）

> 面向学生组织面试官（无需编程经验）。先读「快速开始」，其余按需查阅。
> 开发者请另读 `接口文档.md`；GUI 用户请读 `docs/GUI使用说明.md`。

## 1. 快速开始（3 步）

1. **准备名单**：各部门交来的 Excel/表格名单——
   - **可直接放 `.xlsx` / `.xls` / `.txt` / `.csv`**，不用再另存转换；
   - 文本格式要求：每行一个人，含一段汉字姓名（≥2 字）+ 恰好 10 位数字学号；
   - 少数民族姓名请用 `·` 连写（如 `麦麦提·吐尔逊`），**不要**用空格分两段；
   - 表头行、电话、备注等不影响导入；无法解析的行会在结果里列出（最多 3 条）。
   - 默认读取当前目录 `名单.txt`（菜单 1 可输入任意路径）。
2. **启动**：
   - Linux：首次 `bash scripts/fetch-libs.sh`（联网下载组件；公司代理可加
     `-x http://代理地址`），然后 `bash scripts/build.sh`，之后每次 `bash scripts/run.sh`；
   - Windows：`scripts\fetch-libs-v2.bat`（下载 H2+POI；打包链用的 GBK 版 fetch-libs.bat 不含 POI，
     二期 Excel 功能请用 v2 版）→ `scripts\build.bat`，cmd 里先 `chcp 65001`，再 `scripts\run.bat`
     （需 JDK 17）。
   - 生成 Excel 验收样例/一键验收仅开发者路径需要：见 README（需 python3+openpyxl/xlwt），日常使用无需 python。
3. **菜单操作**：输入编号回车；`0` 退出。数据存于 `data/`，重启接着用。

## 2. 主菜单速览（二期）

```
1  导入名单文件（txt/csv/xlsx/xls）      7  分数附加（单笔 0~10，写原因，可多笔）
2  面试打分（四维，每维 0~25）           8  撤销最近一次评分操作
3  查看候选人名单与状态                  9  初始化系统（清评分，保留名单）
4  查看排名与评分明细                   10  名单管理（新增/改名/改学号/删除）
5  导出 CSV（Excel 打开不乱码）         11  彻底重置（危险！删除一切数据）
6  分数补录（已结束者补一条四维）          0  退出
```

顶部状态行含义：名单总人数、未面试/面试中/已结束人数、四维评分记录条数、附加分条数。

## 3. 典型流程

### 3.1 导入名单（菜单 1）
- 输入文件路径（回车=默认 `名单.txt`；Excel 直接给路径即可，如
  `samples/名单样例-四维.xlsx`）。
- 结果显示：`成功解析 X 行（新增 N 人、更新 M 行）/ 跳过 Y 行`，并附 ≤3 条跳过样例与编码标签
  （`Excel(.xlsx)`/`Excel(.xls)`/UTF-8/GB18030…）。
- 新增=没见过的学号；更新=同号再次出现（按最新姓名更新，不会重复）；重复导入安全。
- 试玩样例：`samples/名单样例-规整.txt`、`名单样例-乱序.txt`、`名单样例-四维.xlsx/.xls`。

### 3.2 面试打分（菜单 2）——四维评分
1. 输入姓名（几个字）或学号（可输前几位）→ 选择序号确认；
2. 面试界面：
   - `1 添加评分`：依次输入 **责任心 / 时间管理能力 / 学生工作能力 / 部门契合度** 四个分值
     （各 0~25、最多两位小数），输入 q 可取消本条；
   - 想继续就再选 1；打错可选 `2 删除最近一条`；
   - 打完选 `3 结束评分`：
     - 有 **3 条及以上**：每个维度自动“去掉一个最高、一个最低”取平均，四个平均相加（≤100）
       再加附加分 = 最终分；
     - 只有 **1~2 条**：提示“四个维度无法各自去极值，将按普通平均”，**二次确认**后才结束；
     - 0 条：系统拒绝结束（提示先录入）；
   - `0 暂存退出`：该人保持“面试中”，下次菜单 2 自动提示继续。
3. 注意：同一时间只能面试一个人。

### 3.3 查看排名（菜单 4）
- 只排已结束者：最终分从高到低；**同分先比责任心平均，再比时间管理、学生工作、部门契合**，
  仍同分按学号小者在前。
- 表格含四维平均列与附加合计；输入学号可看某人每条记录的四维明细。

### 3.4 导出 CSV（菜单 5）
- 范围：`1 仅已完成` / `2 全部`（未完成者也带上，适合备份）；回车默认 `data/导出_时间戳.csv`。
- 列：排名、学号、姓名、责任心、时间管理能力、学生工作能力、部门契合度、四维合计、
  平均方式、评分记录数、附加分明细（含原因）、附加分合计、最终分。
- UTF-8 带 BOM：Excel 双击不乱码。

### 3.5 发现问题怎么办
- 未结束：菜单 2 删除上一条后重打；
- 已结束：漏分 → 菜单 6 补一条四维；加才艺分 → 菜单 7（0~10，写原因）；刚输错 → 菜单 8 撤销。
- 撤销按倒序一次一步，只撤评分类操作；不能撤过“初始化”；已结束者不可被撤到 0 条。

### 3.6 名单管理（菜单 10）
- 1 新增：输姓名 + 10 位学号（学号重复会被拒）；2 改名；3 改学号（评分/附加/日志自动
  跟过去，面试中的人不能改）；4 删除（会连带删除其全部评分/附加/日志，**二次确认**，
  面试中的人不能删）；5 查看。
- 被删学号以后可以重新添加。

### 3.7 收尾：初始化（菜单 9）与彻底重置（菜单 11）
- **初始化**：清空全部评分/附加/撤销记录，所有人回到“未面试”，**名单保留**；
  建议先导出备份；二次确认输入 `YES`。
- **彻底重置（危险）**：连候选人名单、数据库文件（`data/scoring.mv.db` 等）以及 data/ 下
  的导出/备份 CSV **全部删除**并原地重建，回到“全新安装”状态。
  流程：先列出将删除的文件清单 → 可选导出留档 → 第一次确认 y/n →
  **第二次必须完整输入 `彻底重置` 四个字**（输错即取消）。
- 两者都不可恢复：动手前务必先导出 CSV。

## 4. 老库（一期格式）怎么办

- 打开程序时若提示“该库为一期标量评分格式：已自动迁移……”，说明检测到旧
  版本数据库并已自动处理：旧评分表改名存档（`score_legacy_v1`），名单保留，
  候选人面试状态统一重置为“未面试”；旧评分不会折算成四维分。如仍需旧分数，
  请在一期程序里先导出 CSV 留档。

## 5. 常见问题（FAQ）

| 问题 | 处理 |
|---|---|
| 导入“跳过 N 行” | 看样例行：无 10 位学号 / 位数不对 / 一行多人；Excel 中检查合并单元格与数字格式（学号列建议文本） |
| 名单里“阿依古丽 买买提” | 改 `阿依古丽·买买提` 后重导（重复导入安全） |
| Excel 导入学号变 2.02312E9 之类 | 那是文件里被存成科学计数法的文本；本系统读 Excel 数字单元格已自动转纯数字字符串；若仍异常请把学号列设成文本格式 |
| CSV 乱码 | 本系统带 BOM 不乱码；其它软件打开请选 UTF-8 |
| 附加分输 11 被拒 | 单笔上限 10 分；可分开多笔加 |
| 输错分已保存 | 未结束：菜单 2 删上一条；已结束：菜单 8 撤销 |
| 中途退出程序 | 已录记录不丢；重启后菜单 2 提示续面 |
| 数据在哪里/备份 | `data/scoring.mv.db` 单文件；备份=退出后复制；恢复=放回 |
| 初始化/彻底重置后还能找回吗 | 不能；执行前用菜单 5 或流程内“先导出留档” |
| 提示“该库为一期格式已自动迁移” | 见第 4 节，正常现象 |

## 6. 数据安全小贴士

- 每轮结束导出 CSV（菜单 5 选“全部”）并备份 `data/scoring.mv.db`。
- 不要同时开两个程序窗口操作同一数据库（CLI 与 GUI 也不能同时开）。
- “彻底重置”会删除 data/ 下全部 CSV，请先移走要保留的导出文件。
