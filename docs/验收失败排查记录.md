### 2.1 排名表断言 ×3 —— `scripts/self-test.sh` L115–117

期望（正则，要求行首 4 空格 + `1 ` 序号前缀）：

```bash
grep -E '^    1 .*王小明'      … 排名 1=王小明(73+9=82)
grep -E '^    2 .*麦麦提·吐尔逊' … 同分 72 按责任心优先：C 第 2
grep -E '^    3 .*阿依古丽·买买提' … 同分 72：D 第 3
```

实际输出（`out/e2e-logs/r6.log` L25–32 原文）：

```
排名  学号        姓名               最终分  四维合计 责任心  时间管理 学生工作 部门契合 平均方式  附加合计  记录数
    12023000101  王小明               73.00   73.00   20.00    17.00    18.00   18.00去极值平均      0.00       4
    22023000103  麦麦提·吐尔逊        72.00   72.00   24.00    16.00    20.00   12.00去极值平均      0.00       3
    32023000104  阿依古丽·买买提      72.00   72.00   20.00    20.00    20.00   12.00去极值平均      0.00       3
    42023000102  李小红               60.00   60.00   15.00    15.00    15.00   15.00普通平均        0.00       2
    52023990002  欧阳娜娜             40.00   40.00   10.00    10.00    10.00   10.00普通平均        0.00       1
排序规则：最终分降序 → 同分比较四维平均（责任心→时间管理能力→学生工作能力→部门契合度）→ 学号升序。
另有 4 人尚未完成面试，不参与排名。
```

观察结论：

1. **排序逻辑本身正确**（王小明 73 第 1；麦麦提/阿依古丽同 72，责任心 24>20 判 C 在 D 前；`排序规则` 说明行也已输出并断言通过），失败的只是“能否按旧格式匹配到行”；
2. **排版缺陷**：行首 `12023000101` = 排名 `1` 与学号 `2023000101` 直接粘连（应为两列，现无间隔，整表相对表头右移错位 1 列）；同类粘连还出现在 `18.00去极值平均` / `15.00普通平均`（部门契合 与 平均方式 两列之间无空格）；
3. 排名列与学号列、部门契合列与平均方式列之间疑似**缺列间隔符**（其余列间距正常），嫌疑在排名表格的打印代码（格式化串/列宽拼接）。
